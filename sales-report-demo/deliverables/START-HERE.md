# Start here — Sales Report Demo

1. Watch sales-report-demo-step-by-step-en.mp4 for the six-step walkthrough (81.5 seconds, English text, no narration).
2. Read sales-report-demo-one-page.pdf for the scope and input requirements.
3. Open sales_report_2010-12-01_to_2010-12-05.xlsx. The three sheets show 84 item lines, 1,503 units and GBP 4,201.25.

This is a portfolio demonstration using selected public records, not a customer project or a general accounting product. The fixed reporting period is December 1–5, 2010, in GBP. It does not establish profit, payments, taxes, freight, discounts or later returns.

Source: Chen, D. (2015). Online Retail. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33 — CC BY 4.0. Records were selected and transformed to a fixed CSV schema. Customer identifiers were omitted. UCI does not endorse this demo.
