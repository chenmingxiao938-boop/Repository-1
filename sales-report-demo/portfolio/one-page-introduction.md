# Sales Report Demo

## A small, local CSV-to-Excel reporting workflow

This demonstration is for a small seller, operations assistant, or analyst who receives a few sales CSV files in the same fixed format and needs a clear weekly sales report without manually rebuilding totals in a spreadsheet.

## What it does

The tool reads one to five CSV files, validates the complete batch, and creates one Excel workbook with three sheets:

- **Order Details** — every accepted invoice line and its line amount.
- **Daily Sales** — selected line count, quantity, and sales grouped by date.
- **Product Sales** — selected line count, quantity, and sales grouped by SKU.

Amounts are calculated from exact integer pence before export. Identifiers remain text, so leading-zero SKUs are retained. The workbook is a snapshot: change the CSV, then export again to refresh every sheet together.

## How to use it

1. Run `app.py` locally.
2. Select one to five CSV files with these columns in this exact order: `line_id`, `order_id`, `order_date`, `sku`, `quantity`, `unit_price`, `currency`.
3. Choose a new `.xlsx` filename and save location.
4. Open the workbook and check the three sheets.

If a batch is invalid, the tool stops, identifies the file, row, and field, and does not create a new report. It does not edit the source CSV files or replace an existing workbook after a failed export.

## Supported scope

This demo accepts GBP invoice-item rows dated from 2010-12-01 through 2010-12-05. It requires positive integer quantities, non-negative prices with at most two decimal places, unique line IDs, and non-cancelled invoice IDs. It is intentionally a fixed-format demonstration, not a general accounting or inventory system.

The report shows selected item sales only. It does not establish tax, shipping, discounts, payment, delivery, profit, or later-return status.

## Evidence in this portfolio

The public sample uses selected records from the UCI Online Retail dataset: 84 lines, 1,503 units, and GBP 4,201.25. The workbook was generated by the same local exporter included in this folder. Program verification: 54 passed, 0 failed. Native Microsoft Excel verification: 11 passed, 0 failed.

**Source:** Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33 — CC BY 4.0. This is a selected-record demonstration; it is not the retailer’s complete sales history, and UCI does not endorse this demo.
