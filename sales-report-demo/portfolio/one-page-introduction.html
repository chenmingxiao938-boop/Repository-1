Sales Report Demo

A small, local CSV-to-Excel reporting workflow

For a small seller, operations assistant, or analyst who receives a few sales CSV files in the same fixed format and needs a clear weekly report without rebuilding totals manually.

1–5CSV files per batch
3Excel report sheets
GBPDemo currency

What it creates

  • Order Details: every accepted invoice line and its line amount.
  • Daily Sales: selected line count, quantity, and sales grouped by date.
  • Product Sales: selected line count, quantity, and sales grouped by SKU.

Amounts use exact integer pence before export. Identifiers remain text, so leading-zero SKUs are retained. The workbook is a snapshot: change the CSV, then export again to refresh every sheet together.

How it works

  1. Run app.py locally.
  2. Select one to five CSV files with the fixed seven-column format.
  3. Choose a new .xlsx filename and save location.
  4. Open the workbook and check the three sheets.

If a batch is invalid, the tool identifies the file, row, and field and does not create a new report. It does not edit source CSV files or replace an existing workbook after a failed export.

Supported scope

This demo accepts GBP invoice-item rows dated from 2010-12-01 through 2010-12-05. It requires positive integer quantities, non-negative prices with at most two decimal places, unique line IDs, and non-cancelled invoice IDs. It is a fixed-format demonstration, not a general accounting or inventory system.

The report shows selected item sales only. It does not establish tax, shipping, discounts, payment, delivery, profit, or later-return status.

Evidence and source

The public sample contains 84 selected UCI Online Retail lines: 1,503 units and GBP 4,201.25. It was generated by the included local exporter. Program verification: 54 passed, 0 failed. Native Microsoft Excel verification: 11 passed, 0 failed.
