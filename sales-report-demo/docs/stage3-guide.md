# 第三阶段：如何看懂核心计算

本阶段已有读取、检查和汇总程序，没有文件选择窗口或Excel导出。全部使用Python自带功能，无第三方依赖。

## 一个真实例子

上一阶段的第一行，line_id为UCI352-000001，商品85123A，数量6，单价GBP 2.55。

1. 读取：把数量读成整数6，商品编号保留文字85123A。
2. 检查：日期在2010-12-01至2010-12-05内，币种为GBP，单价有两位小数，明细ID没有重复。
3. 计算：2.55英镑等于255便士；6乘255等于1530便士，即15.30英镑。
4. 汇总：把1530便士加入2010-12-01的日期小计，也加入85123A的商品小计。

同一商品下次卖2.95英镑时，应按下一行自己的价格计算；不能把全部数量乘第一次的价格。

## 三个函数

- read_items：读取并检查整批文件；任意一行不合法就报出文件、行号和字段，不返回半批结果。
- summarize：只接收已检查的明细，计算总额、按日合计和按商品合计。
- load_report：先调用read_items，通过后再调用summarize；以后界面应调用这个函数。

程序保存金额时使用整数便士。字段pence为420125表示GBP 4201.25。Totals同时保留rows（商品明细行数）和quantity（商品数量）；两者都不是订单数。

## 可自行核对的小练习（不阻塞本次功能验收）

如果某商品有两行：3件、单价0.10英镑；1件、单价0.20英镑。行金额分别为0.30和0.20，总额0.50英镑，程序中为50便士。
